# Roadmap

## v0.1.0 — Initial defensive collector

- System, process, TCP, autorun, service, event-log, and optional file metadata
- JSON output, MSVC build, documentation, and automated compilation

## v0.2.0 — Coverage and usability

- IPv6 and UDP endpoint support
- Startup-folder and scheduled-task inventory
- Process owner, creation time, loaded modules, and hashes
- Structured event fields instead of raw event XML

## v0.3.0 — Analyst workflow

- Configurable collection profiles and time windows
- JSON schema validation
- Redaction helper and report comparison
- Additional tests using synthetic fixtures

The roadmap excludes offensive features such as injection, credential access, evasion, persistence creation, exploitation, or remote scanning.
