# Security policy

WinTriage is an educational defensive tool and is not a substitute for a supported incident-response platform.

Report committed secrets, unexpected data exposure, unsafe behavior, or automation vulnerabilities through GitHub's private vulnerability-reporting feature. Do not attach real incident evidence, credentials, personal data, or malware. Ordinary correctness issues can use the public issue tracker.

The project does not accept offensive capabilities, including exploitation, injection, credential theft, evasion, persistence creation, destructive actions, or unauthorized remote access.
